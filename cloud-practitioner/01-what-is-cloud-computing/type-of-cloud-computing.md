# Types of Cloud Computing

## On-premises

- You manage: Applications, Data, Runtime, Middleware, O/S, Virtualization, Servers, Storage, Networking
  -> The highest level of control, but also the highest level of responsibility.

## Infrastructure as a Service (IaaS)

- Provide building blocks for cloud IT
- Provides networking, computers, data storage space
- Highest level of flexibility
- Easy parallel with traditional on-premises IT
- You manage: Applications, Data, Runtime, Middleware, O/S
- AWS manage: Virtualizations, Servers, Storage, Networking
- Example: EC2, ...

## Platform as a Service (PaaS)

- Removes the need for your organization to manage the underlying infrastructure
- Focus on the deployment and management of your applications
- You manage: Applications, Data
- AWS manage: Runtime, Middleware, O/S, Virtualization, Servers, Storage, Networking
- Example: Elastic Beanstalk, ...

## Software as a Service (SaaS)

- Completed product is run and managed by the service provider
- AWS manage: Applications, Data, Runtime, Middleware, O/S, Virtualization, Servers, Storage, Networking
- Example: Gmail, Microsoft 365, ...

## Pricing of the Cloud

- AWS has three pricing fundamentals, following the pay-as-you-go pricing model
  Compute: Pay for compute time
  Storage: Pay for data stored in the Cloud
  Data transfer out of the cloud, data transfer in is free"
