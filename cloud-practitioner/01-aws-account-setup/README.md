# Set Up an AWS Account

## 📌 Overview

In this project, I set up and secured my AWS account and configured billing alerts to monitor AWS costs.

## 🛠️ What I Did

- Set up an AWS account.
- Learned about the AWS Root User.
- Secured the Root User with a strong password.
- Learned about AWS Free Tier and billing.
- Enabled Free Tier usage alerts.
- Learned about AWS Basic Support.

## 💡 Key Takeaways

- The Root User has full access to the AWS account and should not be used for everyday tasks.
- AWS accounts should be protected with strong security practices.
- Usage and billing alerts help avoid unexpected AWS costs.
